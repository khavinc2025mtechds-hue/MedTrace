# Regulatory corpus

See `source_manifest.json` for exact official URLs, local files, snapshot applicability and retrieval dates. Current eCFR Part 803 and §820.35 snapshots generate 72 chunks. The source HTML is retained for reproducibility. Rebuild with `python -m src.rag.regulatory_retriever --build`.

This is a limited corpus, not a complete compliance library. Add relevant FDA MDR guidance and QMSR guidance as local PDF/text with provenance before claiming guidance coverage. Obtain historical snapshots for historical analysis. Licensed ISO text is not included.
